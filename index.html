About Me

I'm a backend-focused developer who builds systems that run unattended and stay up: async APIs, message-queue-driven workers, scheduled jobs and the infrastructure around them. Most of my recent work has been on WhatsApp integration platforms, SMS/number sales panels and proxy gateways — services that talk to flaky external providers and still need to be reliable, observable and easy to scale horizontally.

Day to day that means FastAPI and Flask on the Python side, Go for lean network-facing services, and NestJS when a project calls for TypeScript — wired together with RabbitMQ/SQS, Redis pub/sub, Docker and, where it matters, OpenTelemetry + Grafana so I can see what the system is actually doing in production.
